# Daily Actions 누락 원인 및 검증 기록

## 확인한 원인

실행 [42534174166](https://github.com/jemjemjemm/daily-energy-dashboard/actions/runs/42534174166)은 2026-11-09 Morning Daily를 만든 뒤 성공으로 종료했다. 국감 검색·검토·발간 단계가 workflow에 없었고, 완료 파일은 Daily의 HTML 검증 직후 작성됐다.

유가는 생성 실패가 아니었다. 별도로 호출한 [42534248068](https://github.com/jemjemjemm/daily-energy-dashboard/actions/runs/42534248068)은 원수집 3건으로 Morning 1건, 전일 Night 0건을 생성하고 08:16경 커밋 `2a05070`을 저장했다. Daily는 이 결과를 기다리지 않았으며, 유가 호출 실패도 `continue-on-error`로 허용했다. 당시 유가 호출은 당일 마감 10분 이후에만 가능해 과거 날짜·기간 실행에서는 호출되지 않았다.

그 전에 시작된 [Pages 배포 42534255801](https://github.com/jemjemjemm/daily-energy-dashboard/actions/runs/42534255801)은 08:15:19에 Daily 커밋 `192c431`을 가져와 배포했다. 따라서 이 배포 산출물에는 뒤에 커밋된 유가 파일이 없었다. 이후 보완 발간한 `d592052`의 검토본은 이번 작업에서 보존했다.

## 변경

- Daily Action 안에서 국감 3개 상임위, 동일 슬롯 유가와 Morning 전일 Night, Monitoring 完을 함께 처리한다.
- 전체 묶음의 날짜·슬롯·검토 근거·색인·본문을 검증한 후 완료 파일을 작성하고 한 번에 커밋한다. 분리된 유가 workflow 호출은 제거했다.
- Daily만 남은 과거 완료 파일은 재실행을 막지 않는다. 단일 날짜·기간 재실행은 이미 있는 시간대의 Daily 기사·검토 요약을 보존하고, 누락 시간대만 새로 수집한다. Morning 재실행도 기존 Evening 기사를 보존한다.
- 단일 날짜뿐 아니라 기간 실행에도 동일 슬롯의 부속 보고서를 생성한다. 기간 HTML의 펼침 슬롯을 입력값과 일치시켰다.
- 신규 국감 수집은 주제별 3개 검색원 결과와 제외 사유를 보존하고, 발행사 원문 본문·최초시각을 확인한 후보만 분류한다. 검색 장애·원문 확인 실패는 빈 뉴스로 발간하지 않고 실패로 기록한다. 기존 검토본은 재사용한다.
- 신규 연결 검사에서 설정된 Anthropic API가 잔액 부족 HTTP 400을 반환했다. 유료 API를 필수 의존성으로 두지 않고, 명시적인 상임위·의원 역할·명단·소관 부처와 원문 제목을 사용하는 보수적 기본 분류를 추가했다. API 사용 불가와 기본 분류의 한계는 검토 파일에 기록한다. 불명확한 분류·요약은 제외한다.
- 유가 Night에도 Morning/Evening과 같은 원문 확인 절차를 적용한다. 자동 확인과 사람의 편집 검토를 구분하고 미확인 기사를 `verified=false`로 보존한다. 원수집 수와 후보별 제외 기록을 남긴다.
- Daily와 독립 유가 workflow는 같은 실행 잠금을 사용해 동시 커밋 충돌을 줄인다.

## 재현 방법

같은 **Daily Energy Dashboard - Daily Data Pipeline**의 Run workflow에서 다음을 지정한다.

- `simulate_only`: `true`
- `date_from`: `2026-11-02`
- `date_to`: `2026-11-06`
- `report_slot`: `morning` (시뮬레이션은 두 슬롯 모두 검사)
- 선택 사항 `collection_probe_date`: 신규 국감 수집 연결 검사 날짜

시뮬레이션은 실제 발간에 쓰는 생성기와 `tools.report_bundle` 검증을 호출한다. 조립 사이트를 검증하고 결과 및 신규 수집 검토 자료를 Actions의 `report-bundle-simulation` artifact에 보관한다. 시뮬레이션은 커밋·발간하지 않는다. 정상 발간은 `simulate_only=false`를 사용한다.

로컬에서는 별도 작업 사본에서 다음을 실행한다.

```powershell
python -m tools.simulate_report_bundles --start 2026-11-02 --end 2026-11-06
```

총 10개 슬롯, 국감 30개 위원회 섹션, 유가 15개 보고서 연결을 확인했다. 단일 조립 사이트 검증에서 Daily/국감 170개 날짜와 유가 파일 884개의 보존을 확인했다. 320·390·1280px 브라우저에서 순서·본문·링크·접기·날짜 전환·가로 넘침 검사를 통과했다.

과거 검색 결과를 현재 시점에 완전히 재현할 수는 없다. 10개 슬롯 재생은 저장된 일정·기사·편집 검토 자료를 사용한 생성 및 배포 산출물 검증이다. 신규 검색·편집 API 연결 검사는 별도 probe로 구분한다.

GitHub의 [수정본 검사 42580408534](https://github.com/jemjemjemm/daily-energy-dashboard/actions/runs/42580408534)는 10개 슬롯 재생과 신규 국감 수집 검사를 모두 통과했다. 신규 검사는 검색 결과 276건을 검토했고, 원문·최초시각 확인 4건 중 소관·의원 역할을 확인한 1건을 기본 분류로 채택했다. 공개 검색·발행사 원문 접근 한계가 크므로 이 결과는 전체 뉴스 전수 확보를 뜻하지 않는다. 검증 제한은 화면에서도 표시하며, 제한으로 확인 기사를 확보하지 못한 위원회를 ‘뉴스 없음’으로 표시하지 않는다. 기존에 보완한 11/9 발간 검토본은 이 probe로 교체하지 않았다.

실제 [11/9 Morning 재실행 42580877553](https://github.com/jemjemjemm/daily-energy-dashboard/actions/runs/42580877553)에서도 묶음 생성·검증·완료 기록·커밋을 통과했다. 이 과정에서 기존 Daily 기사를 다시 선정하며 요약이 기본 요약으로 바뀌는 회귀를 발견해 위 보존 조건을 추가했고, 11/9의 기존 검토 기사·요약을 복구했다. 최종 묶음은 산중위 5건·기노위 4건·재경위 2건, 유가 Morning 18건·전일 Night 4건, Monitoring 完 보고서 27건이다.
